# 课程重构执行计划

> 本文件写给执行者（人或本地 coding agent）。形式规范见 [`template.md`](template.md)。
> 本计划只定方向、结构和验收标准；数值参数、具体脚本和文案在执行时决定，进度与决定记录在 `handbook/status.md`（批次 0 中创建）。

---

## 0. 为什么要重构

现在的网站逻辑混乱，原因有四个：

1. K/L 两套编号加 `-E/-O/-S` 后缀，学习顺序要靠一张依赖图才讲得清；
2. 作者文档与学员页面混在一起，同一份进度写在四处（`STATUS.md`、`docs/course/status`、课程设计稿、各课页面），而且已经不同步；
3. 19 个课号全部公开，只有 3 个有实验；草稿页里有引用不存在结果的练习；
4. 早期实验全部完美恢复（误差约 1e-14），"激励""可辨识性"讲不出可见的后果。

目标：**一条线性课程、一个学员站、一本作者手册、一份进度台账**，然后按批次补齐课程。

| 噪声 | 第 01、02 课无噪声；第 03 课引入；第 06 课专门讲观测质量 |
| 动画 | 无声 + 字幕，只渲染一版，每课 0–2 段；解释写在上下方 HTML |
| 网页交互 | 预计算交互图（离散选项、先预测再揭晓），不在浏览器里跑模型或拟合；暂不做 Pyodide / Marimo WASM |
| 3D 展示 | 第 09 课起用本地运行 + 网页回放；浏览器实时仿真只作为经验证后的可选增强 |

| 自托管 | 所有 JS 库、查看器、字体与课程同源部署 |
| 仿真后端 | 多体与接触用 MuJoCo；整机需要 GPU 并行时用 mjlab |
| 硬件课程 | 不进本轮课程目录，只保留在 `handbook/design/` 的路线图中 |
| Review | 目前由维护者本人 review，不设为阻塞项；以后再请其他人交叉 review |

### 2.3 难度递进

| 课 | 观测 | 新增的一个困难 |
|---|---|---|
| 01–02 | 理想 | 无，先走通闭环 |
| 03 | 位置噪声（固定强度） | 激励不足在噪声下有了可见代价 |
| 04–05 | 默认理想；带噪版本可作为延伸 | 延迟；摩擦 |
| 06 | 位置噪声 + 差分速度 | 观测质量本身 |
| 07 | 同 06 | 限幅 |
| 08 | 同 05 | 补偿解 |
| 09 起 | 默认带噪编码器 | 耦合、接触、规模、失配 |

**第 03 课的验收重点：** 在相同时长和幅值预算下，慢输入的多次重复估计明显更分散或偏差明显更大，宽频输入更稳定。如果调参后仍看不出差别，先停下来与维护者讨论实验设计，不要硬写结论。

## 5. 分批执行

每批完成后更新 `handbook/status.md`，由维护者 review 中文页。Review 不阻塞下一批开工，但第 03 课的实验结果出来后要先停下来确认。

### 批次 0 · 结构与工具

- 按第 4 节建立 `course/`、`handbook/`、`sysid_lab/`、`artifacts/`，迁移文件；
- `pyproject.toml` + `uv.lock`；`sysid-lab run NN` 命令行；现有 L0、L0-E、L1、L1 摩擦实验迁入后结果不变（与迁移前的产物比对）；
- 产物 manifest（模板第 11 节）与数字占位符渲染；
- 改写 `tools/build_course.py` 与 Pages 工作流，部署根改为 `course/` 的构建输出；
- 构建检查：禁用词扫描、证据标签、数字占位符、死链、首屏体积；CI 重跑管线并在容差内比对产物；
- 自托管 uPlot 与 Plotly 精简构建到 `course/vendor/`；实现模板中的组件样式：页头信息条、先预测框、动画块、交互图块、三行解读、证据标签、信号表、三行小结；
- Manim 场景改浅色主题和固定角色配色，数值从 `artifacts/` 读取；
- 仓库根目录新增 `AGENTS.md`（`CLAUDE.md` 指向它），写明：先读 `handbook/template.md` 和 `handbook/plan.md`；进度只写 `handbook/status.md`；网页 JS 不实现模型；
- 精简根目录 `README.md`：项目定位、网站链接、本地运行三行命令、手册链接。

**验收：** 站点能构建并部署；首页只有第 3 节列出的内容；手册不在部署产物里；迁移后的实验产物与迁移前一致；CI 通过。

- 第 03 课：L0-E 加噪声重跑，重做动画和交互图；
- 第 06 课：观测噪声与差分速度；
- 第 07 课：力矩限幅（选修）；

**验收：** 第 03 课满足 2.3 节的验收重点；三课通过检查表。

### 批次 3 · MuJoCo 多体与接触

- **技术验证（先做）**：用同一次两关节腿运行，分别试 Viser 静态录制、自写 three.js 回放、MeshCat 静态 HTML，在桌面和手机上对比加载体积与流畅度，选定一种写回模板第 7.3 节；可顺带评估 MuJoCo 官方 WASM 能否在目标手机上运行；
- 共用基础：锁定 MuJoCo 版本；两关节固定基座腿模型、数据生成与拟合接口、回放导出；
- 第 09 课：A/B/C/D 四个案例（刚体误差 / 执行器误差 / 两者共存 / 加部件约束）；
- 第 10 课：法向接触，拟合前后都要重跑自由空间验证。

### 批次 4 · 整机与失配

- 第 11 课：Microduck。先确认 MuJoCo 能直接完成；需要 GPU 并行时再引入 mjlab，并在页头标明"需要 NVIDIA GPU"；
- 第 12 课：Microban 参数共享；
- 第 13 课：先做 MuJoCo 内的结构失配案例，再选第二引擎做跨引擎案例。
