# L1：伺服驱动负载摆

固定运行使用 `l1-servo-loaded-pendulum-v2`。讲解与练习从 [L1 课程](../../docs/lessons/l1/index.zh-CN.md)开始。

## 装置与边界

固定基座支撑一个旋转伺服轴、一根均匀刚性臂（1.2 kg、0.6 m）和已知点负载（0.35 kg）。重力为 9.81 m/s²。角度零点向下，正角度使负载向右移动。包含臂和负载的已知惯量为 0.27 kg m²。

`q_des + 关节状态 → 固定 PD 控制器 → 指令延迟 → 力矩 → 摆`

控制器计算 `kp * (q_des - q) - kd * internal velocity`，其中 kp=8 N m/rad，kd=4 N m s/rad。延迟作用于 **PD 之后的完整力矩指令历史**，包括反馈项。非整数采样延迟使用线性插值；重置之前的指令为零。每个 0.005 s 区间内力矩保持不变，由 RK4 积分重力动力学。不使用滤波或速率限制。

估计器只接收 `t`、`q_des`、理想编码器 `q` 和由位置中心差分得到的 `qd`（端点使用单边差分）。内部速度、Oracle 力矩和延迟缓存属于特权诊断。参数命名空间、激励参数、单位、随机种子、合成时间戳起点、重置状态及配置哈希保存在 [metrics.json](metrics.json)。时间戳是冻结的合成起点，不是声称的实际采集日期。

## 如何阅读证据

![机械装置、拟合与验证、残差和局部损失切片](report.png)

拟合扫频与留出换向使用不同频率/相位组成，都重置为 q=0 rad、内部速度=0 rad/s。只有扫频进入优化；选定拟合延迟后再评估验证。机械面板显示一帧记录下来的验证状态，使用与曲线相同的角度数组；交互时间轴回放这些数组。

图例对照：**Oracle 为黑色实线；Initial 为橙色初始模型；Identified 为蓝色虚线和空心标记；target 为绿灰色点线目标。** 本例结构匹配，Oracle 与辨识后曲线预期重合。力矩行中的延迟前 Oracle 指令和实际施加力矩只用于评估。Fit 表示拟合，Validation 表示验证，residual 表示残差。

残差定义为 `model - Oracle`。初始模型在换向附近留下重复的正负波瓣；残差—速度图显示时序误差结构。小的时间偏移常产生与速度成比例的误差，因此相关性不能单独证明摩擦。辨识后残差接近零，是因为单延迟模型匹配了生成器。

只用拟合数据的局部损失切片，在机械参数固定时测试九个相邻延迟。最小值支持局部延迟敏感度，不是置信区间，也不证明任意指令下都可辨识。缓慢激励可能使谷底变浅。有界最小二乘从独立起点开始；若未缩放的 q/qd 总损失超过 1e-8，再尝试七个均匀分布的公开起点，选拟合损失最低的结果。验证评分或 Oracle 参数不会参与起点选择。

## 参数与留出预测

| 角色 | 等效延迟 | 机械参数 |
|---|---:|---|
| Oracle（仅评估可见） | 0.08000 s | 固定的已知臂和负载 |
| 初始模型 | 0.00000 s | 相同已知值 |
| 辨识后 Student | 0.08000 s | 相同已知值 |

公开边界：[0, 0.2] s。优化器起点：0.03 s，与初始模型独立。拟合成功：True。求解器信息：满足 `gtol` 终止条件。

| 数据 | 初始 q RMSE（rad） | 辨识后 q RMSE | 初始 qd RMSE（rad/s） | 辨识后 qd RMSE |
|---|---:|---:|---:|---:|
| 拟合扫频 | 0.00442141 | 9.4514e-18 | 0.0177397 | 1.85405e-16 |
| 留出换向 | 0.0308547 | 6.00653e-17 | 0.490069 | 1.10139e-15 |

默认验收阈值：延迟恢复误差 ≤ 1 ms，留出 q **和** qd 的 RMSE 降幅均 ≥ 90%。本次延迟误差为 6.93889e-17 s，详细改善比例见 `metrics.json`。这是匹配合成基准的阈值，不是硬件精度保证。拟合延迟是**依赖边界和采样的等效量**，不是物理电机常数。

## 复现与局限

在仓库根目录运行：

```bash
python -m synthetic.l1_servo_loaded_pendulum --output-dir reports/l1_servo_loaded_pendulum
```

相同配置重新生成报告和指标。相同环境下结果确定；跨 CPU/库版本时，延迟和指标使用 1e-8 绝对容差，并比较图中内容而非 PNG 字节。Notebook 和应用共用同一数值模块。

本课是观测理想的合成实验，不是电机电磁模型或整机仿真，不建立硬件迁移结论。省略项包括力矩比例/偏置、摩擦、饱和、柔性/回差、传感器噪声、电压/温度、接触、负载变化和折算电机惯量。只有残差证据具体支持时再加入摩擦或饱和，随后用固定基座腿研究耦合动力学。
