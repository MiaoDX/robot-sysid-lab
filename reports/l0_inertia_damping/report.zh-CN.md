# L0 惯量与阻尼辨识

本报告是 [L0 课程](../../docs/lessons/l0/index.zh-CN.md)的固定运行结果。问题是：能否从观测运动估计单自由度系统的惯量与黏性阻尼？

## 如何阅读报告

系统满足 `J*qdd + b*qd = u`。`u` 为实际力矩，`q` 为位置，`qd` 为速度。**真实系统（Oracle）** 是生成观测的隐藏教师；**初始模型** 是辨识前看似合理但故意设错的模型；**辨识后模型** 是在拟合轨迹上估计 `J` 和 `b` 后的结果。初始模型用于展示为什么需要辨识，并不是另一份真值。机器可读配置仍保留 `nominal` 键以兼容实现。

估计器使用拟合轨迹。验证轨迹采用另一种多正弦输入，在拟合完成前保持不参与调整。验证改善，才支持模型学到了动力学，而不只是匹配某一条运动。

**扫频（chirp）** 是频率从低到高变化的单个正弦信号；**多正弦（multisine）** 是多个固定频率正弦信号之和。**留出**表示多正弦观测不用于估计 `J` 或 `b`，只在拟合后检验另一种运动的预测。

配置：`l0-inertia-damping-v1`<br>
系统边界：已知实际力矩 `u`（N m）→ 观测 `q`、`qd`<br>
拟合激励：扫频<br>
验证激励：留出的多正弦

![真实系统、初始模型和辨识后模型的轨迹](report.png)

**读图对照：** True system / Oracle 是深色实线；Identified model 是蓝色虚线和空心标记；Initial model 是橙色。即使真值与辨识后曲线重叠，标记仍能显示两条曲线都存在，重叠支持当前条件下匹配成功。Fit 表示拟合，Validation 表示验证；position 为位置，velocity 为速度，time 为时间。

## 结果支持什么，不支持什么

辨识参数恢复了这个结构匹配的解析教师，并预测了留出激励。这是一次受控的初步成功，不表示真实伺服可以仅用这两个项描述。实验省略了力矩校准、控制器动力学、延迟、饱和、黏性阻尼以外的摩擦、柔性、接触及传感器噪声。[课程讲义](../../docs/lessons/l0/03-assumptions-and-next-step.zh-CN.md)解释这些省略如何引出下一项实验。

## 亲手试一试

阅读 [L0 课程](../../docs/lessons/l0/index.zh-CN.md)，在[本地 Marimo 应用](../../apps/l0_inertia_damping.py)中改变一个初始模型参数。橙色预览立即变化；点击 **Run identification（运行辨识）** 更新蓝色结果。成功的拟合应仍恢复 Oracle 参数。

用以下命令重新生成原始报告：

```bash
python -m synthetic.l0_inertia_damping --output-dir reports/l0_inertia_damping
```

估计器只接收拟合数据中的 `t`、`u`、`q`、`qd`、公开边界和不包含真值的初始参数。Oracle 参数只用于评估展示。这个结构匹配、观测理想的例子展示参数恢复与留出预测，不建立模型失配或真实机器人迁移的结论。
