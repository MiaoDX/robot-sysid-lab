# L1 摩擦扩展：摩擦与黏性阻尼

本次冻结的 CPU 实验比较只含黏性阻尼的 Student 与能够表示平滑类库仑阻力的 Student。已知惯量旋转负载满足：

`J*qdd + b*qd + tau_c*tanh(qd/v_eps) = u`

![拟合、验证、阻力和换向残差](report.png)

## 边界与观测

Oracle 使用 `b=0.055` 与 `tau_c=0.06`，固定 `J=0.065`、`v_eps=0.04`。估计器只能接收 `t`、实际力矩 `u`、位置 `q` 和速度 `qd`。Oracle 参数、阻力分解和留出观测不进入拟合接口。

## 结果

纯黏性拟合得到 `b=0.097292`。摩擦 Student 得到 `b=0.055000`、`tau_c=0.060000`。留出位置和速度 RMSE 比分别约为 `1.18e-18` 和 `2.67e-17`；换向窗口残差比约为 `1.22e-19`。局部拟合敏感度条件数为 `15.24`。

换向附近的结构化残差说明候选模型缺少某种效应，但仅凭速度相关残差不能证明一定是摩擦；延迟、滤波或错误的力矩边界也可能产生相似图案。

## 限制

本课使用平滑的 `tanh` 摩擦，不覆盖静止黏着、Stribeck、回差、传感器噪声或硬件迁移。阈值在 pilot 后冻结：验证误差比不超过 `0.25`，换向残差比不超过 `0.4`，参数恢复误差不超过 `0.002`（仅在敏感度支持时报告）。
