# L1 · 拟合、验证与相位残差

拟合时，我们寻找一个能解释扫频观测的延迟值，再与假定零延迟的初始模型比较。搜索范围与优化器起点在运行前选定，不使用验证数据或真实延迟来选择。

| 划分 | 激励 | 是否用于拟合 | 问题 |
|---|---|---|---|
| 拟合 | 扫频 | 是 | 记录的运动能否揭示延迟？ |
| 验证 | 留出换向波形 | 否 | 拟合出的延迟能否预测另一种运动？ |

比较真实系统、初始模型和辨识后模型的位置与速度曲线。拟合后的误差变小还不够，我们还要看另一组运动的预测是否改善。报告分别列出初始模型和辨识后模型的误差，便于直接对照。

## 如何读残差

残差定义为所选量的 `model - observed`，即模型预测减去观测。换向附近反复出现的正负波瓣可能是时序线索：初始响应超前或落后于带延迟的 Oracle。

对小的时间偏移，位置残差近似与速度成比例，因此残差—速度图也可能显现相位失配。但相关性本身不能证明摩擦：延迟和速度相关效应都可能产生类似结构，需要受控实验区分。

本例结构匹配、观测理想，辨识后残差接近零支持恢复配置中的等效延迟；它不证明真实伺服只有延迟这一种效应。

机械动画回放已记录的状态。拖动时间轴不应重新仿真或拟合。即使 Oracle 与辨识后数组重合，曲线也保留不同标签和线型。

## 想一想

1. 为什么只看拟合误差，证据不够强？
2. 辨识后验证误差降低，对留出指令说明了什么？
3. 如果验证误差仍高，从另一个起点重复拟合能怎样区分优化问题与缺失效应？

参考答案：只看拟合不能发现泛化不足；留出误差降低说明对未参与拟合运动的预测改善；从独立起点重复拟合，可以在加入新的物理效应之前检查收敛性。
