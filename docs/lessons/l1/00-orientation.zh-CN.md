# L1 · 认识装置与问题

L1 用一个带负载的摆臂研究指令延迟。我们先看一段指令怎样经过控制器、驱动摆臂，再用记录的运动估计这段已知指令路径中的延迟。

```text
位置指令 q_des
    → 固定 PD 控制器
    → 指令延迟
    → 执行器力矩
    → 重力作用下的负载摆
    → 编码器位置 q 和推导速度 qd
```

仿真中的装置由固定基座、一个旋转轴、刚性摆臂和末端负载组成，并受到重力作用。臂长与质量已知，末端负载按已知质量的点负载计算。角度 `q` 从竖直向下的位置起算，单位为 rad；正速度表示角度正在增大。

系统使用解析动力学模型：

$$
I\ddot q = \tau - g\ell\left(\frac{m_a}{2}+m_p\right)\sin q,
\qquad I = \frac{m_a\ell^2}{3}+m_p\ell^2,
$$

`m_a` 是均匀臂质量，`m_p` 是点负载质量，`ell` 是臂长。臂贡献分布惯量及作用于中点的重力，负载作用于末端。这些量和 PD 控制律都固定且已知，需要估计的量只有等效延迟。

| 角色 | 在实验中的含义 |
|---|---|
| Oracle | 使用配置中的非零指令延迟生成观测 |
| 初始模型 | 辨识前使用明确可见的零延迟假设 |
| 辨识后模型 | 根据拟合实验的观测估计延迟 |

图中有时会显示真实力矩和延迟指令，帮助我们理解运动。拟合程序使用的是时间、目标位置、观测位置和推导速度，代码分别记作 `t`、`q_des`、`q` 和 `qd`。
