Servo-driven loaded pendulum

A delay is invisible in a drawing of the machine. Can it still be identified from the motion it causes?

01 · Locate the hidden boundary

The position command goes through a fixed PD law. The hidden delay sits after the torque command and before the actuator input.

02 · Make the phase clue visible

The delay remains 0.080 s, but a chirp's cycles get shorter. The same time delay therefore occupies a larger share of each cycle.

03 · Test held-out prediction

The delay is fit on one excitation and evaluated on a separate validation motion. The identified model should predict the withheld trajectory.
