# L1-S · 让力矩限幅显现出来

一个温和的实验无法揭示从未触及的输出上限。本选修课利用这一事实，区分“拟合不需要限幅”和“数据真正测到了限幅”。

本页定义受限实验契约。数值运行器和报告尚未实现，下面的例子是推理练习，不是实测结果。

## 成功拟合仍可能不知道上限 {#failure}

假设指令始终低于真实力矩上限。没有限幅的 Student 和有一个很大上限的 Student 可以产生同样的运动。继续优化不能在等价的上限中选出唯一答案。

先预测指令超过上限后会发生什么：指令继续增大，但实际力矩不再跟随。

## 声明限幅边界 {#boundary}

孤立边界为

```text
力矩指令 → 对称限幅 → 已知转动动力学 → 运动
```

机械参数和力矩比例固定。Student 看到指令和声明的运动观测；实际施加力矩是 Oracle 诊断信号，不进入拟合。排除延迟和额外摩擦，让新效应只有输出限幅。

只有数据真正跨过并识别阈值时，参数 `tau_max` 才能被恢复；否则诚实结论可能只是下界。

## 比较阈值以下和跨阈值数据 {#comparison}

使用时长相同、噪声已声明的两组拟合条件：

| 数据集 | 能支持什么 |
|---|---|
| 指令从未触及上限 | 上限以下的行为；不能确定唯一上限 |
| 指令跨过上限 | 如果截平可观测，则支持阈值相关行为 |

两组数据都比较无限幅与有限幅 Student，再使用预先声明的留出幅值族。读取最终分数前，冻结模型选择和幅值范围。

## 阅读限幅证据 {#evidence}

计划图表包括指令与实际力矩、限幅比例、损失随 `tau_max` 的变化、不同幅值下的预测误差，以及截平区域附近的残差。大范围上限产生近似相同损失，说明当前数据最多约束下界。

不要把 Oracle 的实际力矩当作估计器可见信号。它用于解释诊断图和检查数据生成器，Student 必须从声明的观测中推断效应。

## 想一想 {#exercise}

数据 A 使用小指令，所有大于 2 Nm 的上限都给出相同预测。数据 B 在约 1 Nm 附近出现截平，并且无限幅与有限幅模型对一个大留出指令给出不同预测。哪组数据支持限幅假设？还需要检查什么？

<details markdown="1">
<summary>查看参考思路</summary>

B 支持限幅假设，因为它包含能区分候选模型的行为。还要检查截平不是控制器或数值伪影，留出幅值是否在选择前已声明，以及阈值估计在不同种子和相关运动条件下是否稳定。A 只能支持“这次数据没有触及上限”。
</details>

常见误区是在没有跨过限幅时报告唯一阈值。如果还不能判断，先检查指令范围和损失平台，再设计一组声明过的、会跨过候选上限的幅值。当结果能明确写成阈值或下界时再继续。

## 这个实验不能证明什么 {#limits}

恒定对称限幅是教学边界，不是完整执行器模型。随速度、电压、温度、方向和负载变化的上限是其他问题。如果指令从未触及上限，就应报告范围或下界，而不是唯一参数。
