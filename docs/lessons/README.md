# Lessons

Lessons are the learner-facing path through the repository. Each lesson pairs
plain-language explanation with a runnable synthetic experiment and a fixed
report. Start with the [rendered course map](../course/index.html), then enter
the [L0 lesson set](l0/README.md) or the [L1 servo-loaded-pendulum lesson set](l1/README.md).

The reusable structure is documented in the [Lesson / Experiment Pipeline](../lesson_pipeline.md).
The static-first, bounded-WASM, local-deep-dive split is defined in the
[Lesson Delivery Policy](../lesson_delivery_policy.md), with the implementation
backlog in the [Course Delivery Task Split](../plans/course-delivery-split.md).
