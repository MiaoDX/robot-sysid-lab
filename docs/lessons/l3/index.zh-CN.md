# L3 · 在自由空间验证后加入接触

脚可能在自由空间运动中拟合良好，一旦压地或落地就失败。本课只加入法向接触效应，并检查接触证据是否足以解释新残差，同时不破坏上游模型。

切向摩擦、滑移和未知地形是后续独立问题。

## 接触可能暴露上游错误 {#failure}

假设腿的接触轨迹错误。改变连杆质量可能改善力曲线，却让自由空间预测变差。在拟合接触参数前，先重跑 L2 自由空间案例并检查接触事件时刻。

先预测：压入或释放运动的哪一部分能显现刚度，哪一部分能显现阻尼。一次静态压缩可能无法把两者分开。

## 声明法向接触边界 {#boundary}

沿用已经验证的腿：

```text
关节指令 → 已验证的执行器/刚体模型 → 法向接触定律 → 运动与声明的法向力
```

第一个接触定律是固定几何下的柔性法向模型。只有在选定运动能分开两者时，Student 才拟合法向刚度/阻尼。接触求解器内部、精确穿透量和隐藏力仍只用于诊断，除非明确声明为观测。

拟合前要冻结接触定律、积分步长、力采样和地面几何。这些数值设置会影响拟合参数的含义。

## 一次只增加一种接触条件 {#comparison}

使用受控压入/释放或轻微落地运动：

1. 在一个已声明的速度/负载范围上拟合；
2. 留出另一个接近速度或负载；
3. 只重新拟合声明的法向接触参数；
4. 重跑原来的自由空间验证。

步长细化是数值检查，不是新的拟合参数。如果步长改变了结论，要先报告数值限制，再解释刚度或阻尼。

## 阅读接触证据 {#evidence}

这是计划中的接触实验契约。列出的曲线和回归表是必须产出的结果，不是本页已有的实测结果。

证据包应显示接触开始时刻、力—压入量和力—速度视图、运动与力残差、留出行为，以及自由空间回归表。如果 Student 看不到穿透量，只能把它作为 Oracle 诊断图。

分别问三个问题：接触是否在正确时刻开始，力响应幅值是否正确，腿部运动是否保持一致。一个总分可能掩盖其中某一步的失败。

## 想一想 {#exercise}

一次缓慢压缩拟合良好，但更快的释放有很大的力残差；自由空间回归仍然通过。下一次实验应该改变什么？为什么改变连杆质量是无效捷径？

<details markdown="1">
<summary>查看参考思路</summary>

改变接近/释放速度，采集能显现速度相关阻尼的条件，同时固定几何和自由空间参数。连杆质量属于上游刚体模型；用它修复接触误差会消耗已有自由空间证据，也改变拟合结果的含义。
</details>

常见误区是因为连杆参数已经可用，就用它修复接触误差。如果还不能选择，先检查接触开始时刻和自由空间回归，再固定上游模型改变释放速度。当接触结论和自由空间结论保持分开时再继续。

## 这节接触课不能证明什么 {#limits}

它不识别切向摩擦、滑移、未知地形、足部几何，也不同时校准所有接触参数。接触值可能是所选后端和步长下的等效属性。如果刚度和阻尼仍然相关，应报告组合或范围。

L4 会把有限范围内的自由空间/接触证据带到 Microduck 整机比较。继续阅读 [L4 · 比较整机拟合路线](../course-design.zh-CN.md#l4)。
