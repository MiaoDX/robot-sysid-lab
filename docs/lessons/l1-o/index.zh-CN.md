# L1-O · 分清观测质量与系统行为

从带噪位置计算出来的速度，可能看起来像新的物理效应。本实验只问一个更窄的问题：当观测量由另一个带噪观测推导出来时，还有什么证据支持执行器参数估计？

本页先冻结实验契约。数值运行器、固定报告和多次运行结果尚未实现，下面不声称任何测量值。

## 更粗糙的信号可能改变答案 {#failure}

从已经交付的 L1 延迟实验开始。它的估计器得到位置和由位置推导出的速度。现在加入一类已声明的位置噪声。差分可能放大高频噪声，让相邻速度样本产生相关性。

看运行结果前先预测：增加通道可能让曲线看起来信息更多，也可能只是改变目标函数的权重，并没有增加独立的系统信息。

## 声明观测边界 {#boundary}

Oracle 仍包含精确的仿真状态。Student 只能得到以下公开观测：

```text
指令与带噪位置 → 已声明的差分规则 → 派生速度 → 估计器
```

| 信号 | 拟合器 | 评估 | Oracle 诊断 |
|---|---|---|---|
| 指令与带噪位置 | 在拟合划分中可见 | 只在留出评估时可见 | 按已声明种子生成 |
| 派生速度 | 若加入目标函数则可见 | 在留出划分中评分 | 精确速度仍隐藏 |
| 仿真器精确速度 | 隐藏 | 可选评分 | 仅用于解释 |

采样时钟和差分端点必须在拟合前固定。派生通道看起来更平滑，不自动意味着它是更独立的测量。

## 在重复噪声下比较目标函数 {#comparison}

固定系统、指令、控制器、延迟参数化和数据时长，比较：

1. 只使用位置的目标函数；
2. 使用位置与派生速度、并声明通道尺度的目标函数。

为拟合、开发和最终评估使用相互独立且预先声明的噪声种子。权重只能根据拟合数据或明确标为开发的数据选择。不能查看最终评估来选择滤波器、权重或噪声大小。

多次运行要区分估计器波动与系统预测误差。两种目标函数使用相同的留出指令族，精确状态始终不能进入估计器。

## 阅读观测证据 {#evidence}

计划中的证据包包括带噪位置、派生速度、各通道残差尺度、多次种子下的延迟估计分布和留出预测。按以下顺序阅读：

- 差分放大了多少噪声；
- 两个通道是否由同一个位置误差驱动；
- 延迟估计是否随种子变化更大；
- 留出系统预测是变好、变差还是基本不变。

派生通道残差更小，同时参数估计可能更不稳定。观测误差和真实状态误差必须分开报告。

## 想一想 {#exercise}

位置加速度度目标函数的训练误差更低，但不同噪声种子下的延迟估计波动很大。只用位置的目标函数训练误差略高，却有更稳定的留出预测。下一步实验应依据哪一种结果？

## 观测质量不能证明什么 {#limits}

本实验只隔离一种位置噪声模型，不覆盖量化、滤波相位、时间戳偏移、抖动、缺样本或所有传感器融合选择。带噪观测可能扩大不确定性，却没有改变系统；曲线看起来干净，也不能证明参数准确。

下一步概念是 K7，用来区分物理参数和等效参数。[L1-S 限幅实验](../l1-s/index.zh-CN.md)则研究另一种可观测性边界。
