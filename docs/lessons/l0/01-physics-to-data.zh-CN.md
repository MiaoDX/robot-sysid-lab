# L0 · 从物理到数据：惯量与阻尼的影响

方程中有两种不同效应：

- `J` 越大，速度越难改变。同样的力矩产生更小的加速度。
- `b` 越大，运动时耗散的能量越多。力矩较小或为零时，速度衰减更快。

拟合输入使用扫频信号（chirp），频率随时间改变。这样既有较慢运动，也有较快变化，有助于分离与加速度有关的惯量效应和与速度有关的阻尼效应。验证输入是另一段多正弦信号（multisine），用来检验模型对未参与拟合运动的预测。

打开[静态图](../../../reports/l0_inertia_damping/report.png)，或运行[实验文件](../../../notebooks/l0_inertia_damping.ipynb)。从左到右阅读四个轨迹面板：

1. 拟合位置、验证位置；
2. 拟合速度、验证速度。

黑色真实系统曲线是观测目标；橙色初始模型是未校准的基线；蓝色辨识后模型是拟合结果。从速度图观察加速度差异，从位置图观察累积的位置差异。残差较小说明模型在本次实验中重现了对应的观测量。

## 只改一个设置

在本地 Marimo 课程中修改初始模型的阻尼，保持真值和输入不变。橙色曲线会立即变化；蓝色结果保持原样，并标记为与当前设置不一致。点击 **Run identification（运行辨识）**，从新的初始值再次拟合。成功时应仍收敛到相同的 Oracle 参数。

比较新的初始预测与完成后的拟合，再检查验证结果。这样既能看到初始猜测怎样改变误差，也能检查拟合是否仍然得到有效结果。

## 想一想

增大惯量最直接影响的是瞬时加速度，还是施加力矩的符号？答案是加速度。只有实验使参数的影响在数据中显现，数据才有助于估计这个参数。
