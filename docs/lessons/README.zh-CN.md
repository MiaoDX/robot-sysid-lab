# 课程与补充资料

第一次学习时，可以从 [K0 · 为什么需要系统辨识](k0/index.zh-CN.md)开始，再读 [K1 · 系统辨识基础](k1/index.zh-CN.md)，最后进入 [L0 · 估计关节的惯量与阻尼](l0/index.zh-CN.md)。

熟悉这些概念后，继续学习 [L1 · 执行器延迟与摩擦](l1/index.zh-CN.md)。每节课都将讲解、视频、练习和结论放在同一页中，可以连续阅读。

L1 现在还包含一个隔离摩擦与黏性阻尼的执行器实验，通过同一课程页面提供本地 CPU 实验、冻结报告和 Notebook。

## 查找课程

[课程目录](../course/index.zh-CN.html#tracks)展示知识课程、仿真实验和硬件实验。K0–K8、L0、L0-E、L1、L1-O、L1-S 以及 L2–L6 的正式阅读页均已开放，页面统一了教学结构和练习；数值实验报告与仿真器证据会在各课实现后补齐。硬件课程仍标注为“准备中”。

## 深入实验

[L0 补充资料](l0/README.zh-CN.md)与 [L1 补充资料](l1/README.zh-CN.md)提供专题笔记、报告、Notebook 和本地应用。
