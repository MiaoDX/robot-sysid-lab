# 项目资料

这里收集课程设计、实验报告和实现说明。开始学习请回到[课程首页](index.zh-CN.html)，按 K0 → K1 → L0 阅读。

## 课程设计与进度

[课程设计评审稿](../lessons/course-design.zh-CN.md)汇总已确认的 K/L 整体方向，以及正式页面共用的统一结构。[课程讲述与编辑原则](../lessons/course-editorial-principles.zh-CN.md)定义这些页面应采用的学员视角、讲述口吻、证据用语和 refactor 门槛。先看[推荐顺序与必要前置](../lessons/course-design.zh-CN.md#d02)，再按编号查看 [K2–K8](../lessons/course-design.zh-CN.md#d04)、[仿真实验](../lessons/course-design.zh-CN.md#d05)和[单课评审清单](../lessons/course-design.zh-CN.md#d08)。真机部分暂不在本轮范围。[课程进度](status.zh-CN.md)记录现有阅读页、待实现的数值路径，以及还需要收集的学员反馈。

需要了解较长远的安排，可以查看[实验路线图](../03_synthetic_lab_roadmap.zh-CN.md)。这些资料供讨论和维护课程时使用。
