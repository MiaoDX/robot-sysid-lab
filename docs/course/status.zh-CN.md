# 课程交付状态

本页区分现有课程与课程提案。[课程设计](../lessons/course-design.zh-CN.md)描述完整学习路线。

## 已可阅读和运行

K0 和 K1 已有独立的中英文课程，分别介绍学习动机和基本概念。

L0 惯量/阻尼与 L1 指令延迟，已有静态课程、教学视频、讲义、本地 Marimo 应用、Notebook、数值运行器和固定报告。L1 现在还包含一个隔离摩擦与黏性阻尼的实验，提供冻结的本地 CPU 运行器、报告和 Notebook；这个扩展不单独制作浏览器界面。网站提供带语言切换的中英文阅读页面，已有课程共用同一套数值配置与证据。

Marimo 交互应用是本地 Python 应用，其部署和浏览器执行与静态阅读网站分开。自包含 WASM 导出仍在规划中。

## 仍待完成的验收

两课都有工程验证记录，独立学员验收仍未完成。需要实际读者指出初始偏差、解释留出性能、改变一个设置并说明假设。翻译页面或通过自动检查，不能替代学习证据。

## 规划中的课程

K2–K8 是后续知识课程，目前仍在准备。L0-E 与 L1 的其他执行器效应（如饱和和观测质量）仍是提案；摩擦扩展已并入 L1，但仍待维护者学习验收。L2–L6 覆盖固定基座腿、接触、Microduck、Microban 和仿真器失配。H0–H2 将方法应用于硬件。没有对应实现实验的条目仍属于设计提案。
