Robot SysID Lab · 机器人系统辨识

通过实验学习机器人系统辨识

机器人在仿真里运行得很好，到了实物上却可能出现偏差。系统辨识帮助我们从实验数据中了解机器人，改进模型，并检查它能否预测新的运动。

这套课程从一个转动关节开始，逐步研究执行器、机器人结构和硬件实验。你会看到模型为什么出错，怎样用数据修正它，以及结果还需要哪些检验。

    完成第一次辨识

知识与实验交叉学习

K 与 L 怎样搭配学习

K0–K8 按知识主题组织，L0–L6 按实验复杂度递进，两者不按编号一一对应。以实验为主线，在需要时补充知识，并带着实验结果回读。

目前可学习：K0 → K1 → L0 → L1。下面是完整课程的建议顺序；K2–K8、L2–L6 及下述扩展课尚在准备中，当前可直接从 L0 继续 L1。

  1. 01

    K0 → K1 → L0 · 完成第一次辨识

    先理解问题和基本量，再用惯量与阻尼实验走完设计、拟合、验证的最小闭环。

  2. 02

    K4 → K5 → K6 → L0-E · 理解方法

    回读 L0，再用 L0-E 对比不同激励，理解参数何时可被区分、拟合怎样工作，以及为什么还要用新运动验证。

  3. 03

    K2 → K3 → L1 → L1-O · 执行器与观测

    先读动力学基础和指令到力矩链路，再研究 L1 延迟与摩擦、L1-O 观测噪声。L1-S 力矩限幅是选修分支。

  4. 04

    K7 → L2 → L3 · 理解耦合与接触

    区分物理参数与补偿误差的等效参数。回读 K2 的多体耦合与接触内容，先验证自由空间模型，再加入接触。

  5. 05

    K8 → L4 → L5 · 扩展到整机

    先用 K8 区分预测与下游效果，再在 L4 比较辨识路线并检验控制效果，L5 研究参数共享；回用 K4–K7 诊断。

  6. 06

    L6 · 从结构失配到跨仿真器

    回到一个小系统，先隔离结构失配，再在真正不同的仿真器间检验预测；回读 K8 的剩余不确定性。L4 后即可进入，L5 不是必要前置。

这是推荐阅读顺序，各课另列必要前置，具备同等经验可跳读。K4–K6 的实验设计、拟合与验证贯穿主线。完整的前置关系与扩展范围见课程设计评审稿。

K0-K8

知识课程

理解概念，再用它们设计实验、解释结果。

  1. K0为什么需要系统辨识了解模型为什么会偏离实际运动，以及怎样判断改进是否有效可学习
  2. K1系统辨识基础区分输入、状态、观测和参数，为第一个实验做准备可学习
  3. K2机器人动力学理解惯量、重力、关节耦合和接触怎样影响运动准备中
  4. K3执行器建模了解控制指令怎样变成力矩，以及途中有哪些影响准备中
  5. K4设计辨识实验选择能够看出目标参数影响的输入和观测准备中
  6. K5估计模型参数理解参数怎样被拟合，以及优化结果还需要哪些检查准备中
  7. K6检验模型预测用新的实验和残差检查模型在哪些条件下有效准备中
  8. K7理解参数的含义判断拟合值代表物理特性，还是在补偿模型误差准备中
  9. K8把模型用于控制与迁移了解辨识结果怎样帮助控制设计和策略训练准备中
L0-L6

仿真实验

从简单关节开始，逐步研究执行器和整机。

  1. L0估计关节的惯量与阻尼从运动数据拟合两个参数，再用新运动检查预测可学习
  2. L1执行器延迟与摩擦区分时序误差与阻力模型失配可学习
  3. L2固定基座腿研究关节耦合时，怎样区分执行器与连杆模型的误差准备中
  4. L3加入地面接触观察足部接触怎样影响已经验证的自由空间运动模型准备中
  5. L4Microduck 整机比较先研究部件与直接拟合整机的效果准备中
  6. L5Microban 人形机器人探索相似关节之间如何共享参数准备中
  7. L6在不同仿真器之间检验模型模型无法完全匹配时，检查它还能预测哪些运动准备中
H0-H2

硬件实验

把仿真中学到的方法用于实物测量与验证。

  1. H0执行器台架学习校准传感器、记录时序并检查测量误差准备中
  2. H1Microduck / Microban用部件和整机实验检验真实机器人的模型准备中
  3. H2完整人形机器人组织可复现的数据采集、辨识与硬件评估准备中
在每个实验中练习

怎样完成一次系统辨识

先确定想了解系统的哪些特性，再设计实验、记录数据。用这些数据拟合模型后，还需要用另一组未参与拟合的数据检查预测结果。

01确定问题选定输入、观测和要估计的参数
02设计实验让目标参数的影响出现在运动中
03记录数据记录输入与运动，检查单位和时间
04拟合模型调整参数，让预测接近观测
05验证预测用未参与拟合的数据检查结果
06分析误差寻找偏差的规律，决定下一步实验
