Robot SysID Lab · A course in robot modeling

Learn robot system identification through experiments

A robot can work well in simulation and behave differently on hardware. System identification helps us learn from experimental data, improve the model, and test whether it can predict new motions.

Start with one rotating joint, then work toward actuators, robot structures, and hardware experiments. See why models make errors, how data can improve them, and how to evaluate the result.

For robotics engineers who can read a time-series plot. You can read the lessons without installing software; each experiment includes instructions for running the code.

Study knowledge alongside experiments

How to combine K and L lessons

K0–K8 organize knowledge by topic; L0–L6 increase experiment complexity. Their numbers do not pair one to one. Follow the experiments, add knowledge when needed, and revisit it with your results.

Available now: K0 → K1 → L0 → L1. The sequence below is a recommendation for the full course; K2–K8, L2–L6, and the extensions below are still coming later. For now, continue directly from L0 to L1.

  1. 01

    K0 → K1 → L0 · Complete your first identification

    Understand the question and basic quantities, then use inertia and damping to complete a small cycle of experiment design, fitting, and validation.

  2. 02

    K4 → K5 → K6 → L0-E · Understand the method

    Revisit L0, then compare inputs in L0-E to understand when parameters can be separated, how fitting works, and why predictions need a new motion for validation.

  3. 03

    K2 → K3 → L1 → L1-O · Actuators and observations

    Read the dynamics and command-to-torque basics, then study delay and friction in L1 and observation noise in L1-O. Torque saturation in L1-S is an elective branch.

  4. 04

    K7 → L2 → L3 · Understand coupling and contact

    Distinguish physical parameters from effective values that compensate for errors. Revisit coupling and contact in K2, validating the free-space model before adding contact.

  5. 05

    K8 → L4 → L5 · Scale to a complete robot

    Use K8 to distinguish prediction from downstream performance. Compare fitting routes and test control outcomes in L4, then study sharing in L5. Reuse K4–K7 for diagnosis.

  6. 06

    L6 · From structural mismatch to cross-engine prediction

    Return to a small plant, isolate structural mismatch, then test predictions across genuinely different simulators. Revisit uncertainty in K8. L6 is accessible after L4; L5 is not required.

This is a suggested sequence. Each lesson also lists necessary prerequisites, which equivalent experience can satisfy. Reuse experiment design, fitting, and validation from K4–K6 throughout. See the curriculum design draft for dependencies and extensions.

How an identification experiment works

Choose the properties you want to understand, then design an experiment and record data. After fitting the model, check its predictions using observations that were withheld from fitting.
