# 课程交付政策

课程解释应在不运行 Python 时仍有用。因此，每课包含静态核心、可选的浏览器实验和本地完整实验。三种形式共用实验约定与数值来源。

## 三种形式

| 形式 | 目的 | 是否必须 | 执行边界 |
|---|---|---|---|
| HTML 与视频 | 解释问题、边界、实验设计、证据和局限 | 每课必须 | GitHub Pages 上的静态文件 |
| Marimo WASM | 提供少量受限的即时实验 | 可选 | 学员浏览器中的 Python |
| 本地 CPU/GPU 实验 | 支持长任务、大数据、不支持的包和深入练习 | 计算实验必须 | 学员机器或服务器 |

HTML 与视频承载主线。学员无需打开 Marimo，也应理解边界、拟合/验证证据和下一步。WASM 提供短反馈循环，不承担整个实验阶梯的完整计算。

## 新课程任务划分

按以下顺序开展：

### 1. 冻结课程约定

记录学习问题、系统边界、隐藏 Oracle 效应、观测、Student、拟合/验证划分、学员控件、证据与省略项。写 UI 前确定执行预算，包括：

- 预期输入和数据集大小；
- 包和后端依赖；
- 默认 CPU 时长；
- 学员可控的最坏时长；
- 峰值内存估计；
- 操作属于回放、即时计算、交互等待还是任务。

### 2. 构建本地数值路径

实现可导入的 CPU/GPU 模型、冻结配置、数据生成、估计、验证、报告和针对性测试。即使提供浏览器版，本地路径也是参考实现。

长计算必须作为显式命令或任务暴露。展示控件读取已完成结果，不偷偷重新拟合。

### 3. 制作静态课程与视频

先写 HTML 课程并渲染教学短片，再增加可选交互。静态包需要包含：

- 物理或算法设置；
- 模型边界和观测；
- 拟合与留出的内容；
- 初始与辨识后行为；
- 主要残差或失败证据；
- 结论局限；
- 本地完整实验命令。

生成报告记录一次固定运行，支持课程，但不替代解释。

### 4. 判断浏览器实验的形式

仅在以下条件全部满足时增加 Marimo WASM：

- 所需包有 Pyodide/WASM 构建；
- 本地模块和数据可打包或作为公开静态资源获取；
- 控件能回答一个简短的学习问题；
- 默认与最坏运行都符合浏览器预算；
- 不需要 GPU、原生进程、共享内存或硬件访问；
- 浏览器运行不可用时，结果仍可理解。

初版优先回放、参数预览、短仿真和小拟合，不因本地实现支持就开放无界优化器或大数据集。

### 5. 提供本地深入路径

在课程旁说明完整实验，可使用 Notebook、CPU/GPU 命令、更大数据、原生仿真器或排队任务。必须说明预期时长、依赖、输出位置和报告复现方法。

当实验超过浏览器预算时，本地路径承接扩展；它沿用静态和 WASM 的实验约定及配置词汇。

### 6. 分别验证三种形式

1. 打开静态 HTML，确认叙事、视频、链接和证据不依赖 Python 计算进程。
2. 如有 WASM，检查冷启动、一个控件、一次完成交互，以及支持浏览器的控制台/网络错误。
3. 在干净环境运行本地命令，对比仓库中的报告和指标。

## 执行判断

以下是工程指南，不是平台硬限制：

| 预算审阅结果 | 交付选择 |
|---|---|
| 小型纯 Python 计算、短数组、支持的包、通常几秒内 | 增加 WASM 交互 |
| 回放有用，但拟合慢或数据较大 | WASM 展示预计算结果，本地拟合 |
| 原生/GPU 依赖、大内存、长优化、多进程或硬件访问 | 本地/服务器完整计算，HTML/视频配可选回放 |

Marimo 文档给出约 2 GB 的 WASM 内存上限，并说明浏览器并发适配器不提供真正的 CPU 并行。随着课程从单自由度走向腿和整机，后两种选择越来越重要。参见 [Marimo WASM 指南](https://docs.marimo.io/guides/wasm.html)。

## 对实验阶梯的应用

课程范围与前置关系以[统一设计稿](lessons/course-design.zh-CN.md)为准。K 课以静态文字、图表和引用的实验结果为主，不要求独立数值实现。下表描述交付目标；H 保留既有安排，暂不参与本轮设计。

| 级别 | 静态 HTML/视频 | WASM 角色 | 完整实验 |
|---|---|---|---|
| L0 惯量与阻尼 | 核心课程和固定报告 | 小拟合与受限控件 | 本地 CPU 和 Notebook |
| L1 延迟伺服负载摆 | 核心课程、机械解释和报告 | 依赖打包后的小拟合、回放和残差视图 | 本地 CPU 和 Notebook |
| L0-E/L1-O；L1-S 选修 | 激励、观测或限幅的独立受控对比 | 预算检查后可选有限交互 | 本地 CPU |
| L2 固定基座腿 | 解释耦合 | 默认预计算回放或很小的预览 | 本地仿真与拟合 |
| L3 接触 | 接触失效解释 | 静态或回放；小案例满足预算时例外 | 本地接触实验 |
| L4 Microduck | 核心课程、视频、报告汇总 | 汇总/回放 | 本地或调度整机拟合 |
| L5 Microban | 核心课程、规模证据 | 可选结果浏览 | 本地/GPU |
| L6 结构失配与跨仿真器 | 单引擎结构失配和真正跨引擎两案 | 固定结果或回放 | 两个后端的本地复现 |
| H 硬件路线 | 安全与实验规程 | 不在 WASM 执行硬件操作 | 本地与硬件服务 |

这样既能保持课程可读、可部署，也允许计算规模增长，而不要求每位学员在浏览器标签页中下载和执行最大的实验。

## 完成标准

- 静态包本身能回答学习问题；
- 报告和视频使用与数值路径相同的冻结配置；
- 本地实验可复现，并说明资源预期；
- 如有 WASM，明确为可选的有限交互；
- 说明何时应从浏览器切换到本地执行。
